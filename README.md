# TRILUVI Website Starter

## Start in Visual Studio Code
1. Entpacke die ZIP-Datei.
2. Öffne den Ordner `triluvi-website` in Visual Studio Code.
3. Öffne `index.html`.
4. Für eine komfortable Vorschau kannst du die VS-Code-Erweiterung **Live Server** installieren und `index.html` mit „Open with Live Server“ öffnen.

## Dateien
- `index.html` – Startseite
- `css/style.css` – gesamtes Design
- `js/main.js` – mobile Navigation
- `assets/triluvi-logo.svg` – TRILUVI-Logo

Die Website ist bewusst zunächst eine statische Version. Später können wir daraus einzelne Seiten, Magazinartikel, Kontaktformular, SEO und weitere Funktionen machen.
